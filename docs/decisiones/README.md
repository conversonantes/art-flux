## Cómo agregar una

Copia el formato de cualquiera: **Contexto**, **Decisión**, **Consecuencias**. Numera la siguiente (`0010-…`). Si una decisión cambia, no borres la anterior: marca su estado como *Reemplazada por 000N* y escribe la nueva.
